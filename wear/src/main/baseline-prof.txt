# Baseline Profile — Mark (Wear OS)
#
# Tells ART which classes and methods to AOT-compile at install time instead of
# JIT-compiling them on first run. This is the mechanism system apps use to feel
# instant on the first launch and during the first animation.
#
# Placement: wear/src/main/baseline-prof.txt
# AGP picks this up automatically for release builds when the
# androidx.profileinstaller dependency is present.
#
# Syntax:
#   H = hot (called often)      S = startup (runs during app start)
#   P = post-startup            [] before -> method, no prefix -> class
#
# Compose, Wear Compose and the AndroidX libraries ship their own baseline
# profiles, so only OUR classes need listing here.
